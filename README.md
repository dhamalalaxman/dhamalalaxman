## 🚀 Featured Project

### 📧 Spam Email Detection Using Machine Learning

A machine-learning application that classifies emails as spam or legitimate using natural language processing and the Multinomial Naive Bayes algorithm.

**Technologies:** Python, pandas, scikit-learn, NLTK, TF-IDF and Jupyter Notebook

**Key features:**

* Text cleaning and natural language preprocessing
* TF-IDF feature extraction
* Multinomial Naive Bayes classification
* Model evaluation using accuracy, precision, recall, F1-score and confusion matrix
* Comparison with Logistic Regression and Support Vector Machine models
